# YouCloud Web

YouCloud в браузере: сайт и Worker на Cloudflare, логика целиком на устройстве слушателя.

## Как устроено

- **Сайт** (`src/`) — Svelte 5 + Vite. Всё, что решает, что и как спросить у сервисов, работает в браузере.
- **Worker** (`worker/index.ts`) отдаёт сайт и пересылает его запросы к сервисам: `/x/<хост>/<путь>` → `https://<хост>/<путь>`, с заголовками, которые ждёт каждый сервис. Пускает только к хостам сервисов и только запросы самого сайта. Ничего не хранит.
- **Расширение** (`extension/`) нужно для Яндекс Музыки и аудио YouTube. Они не обслуживают IP Cloudflare: Яндекс отвечает 451, YouTube просит «подтвердить, что вы не бот». Расширение отправляет эти запросы из браузера слушателя, с его IP. Без расширения работают SoundCloud и поиск YouTube.

| Сервис | Без расширения | С расширением |
| --- | --- | --- |
| SoundCloud | ✅ | ✅ |
| Яндекс Музыка | ❌ 451 | ✅ |
| YouTube Music: поиск, подборки | ✅ | ✅ |
| YouTube Music: аудио | ❌ | ✅ с домашнего IP; через VPN — с входом в YouTube в этом браузере |

Обложки и звук SoundCloud сайт берёт прямо с CDN SoundCloud. Где SoundCloud заблокирован (ПК без VPN),
они идут через Worker: проба при загрузке и любая упавшая обложка или поток переключают сайт
(`src/lib/media.svelte.ts`), а Worker переписывает адреса внутри HLS-плейлистов на `/x/…`, потому что
Chrome сам играет HLS и иначе брал бы куски с CDN напрямую.

Ссылку на звук YouTube, которую не стал играть `<audio>`, сайт не держит в кэше: тот же трек
запрашивается у следующего клиента YouTube (до трёх попыток).

## Masaki

В браузере Masaki (github.com/GXUser7/Masaki) расширение не нужно и не работает: Masaki сам отвечает
на сообщения сайта (hello с `host: 'masaki'`), ходит в Яндекс и YouTube с IP пользователя и открывает
входы в сервисы своими вкладками. Сайт там без своего фона — лежит на стекле Masaki, берёт его тему
(событие `theme`) и скругления; друзья, очередь и текст выезжают поверх страницы. Мини-плеер Masaki
читает Media Session сайта: обложку, название, позицию и кнопки «следующий/предыдущий».

Раскладка: слева только выбор сервиса, сверху поиск и профиль (друзья, настройки), на странице сервиса —
главное, «Любимое» (лайки, плейлисты, артисты) и подборки.

## Разработка

```bash
npm install
npm run dev      # http://localhost:5190 — сайт и Worker вместе
npm run check    # типы сайта и Worker
```

## Выложить на Cloudflare

```bash
npx wrangler login   # один раз
npm run deploy       # собрать и выложить
```

## Расширение

Сайт сам раздаёт расширение: `/youcloud-extension.zip`. Сборка упаковывает папку `extension/` в zip (`scripts/extension-zip.ts`), а дев-сервер собирает его на лету. Карточка с кнопкой «Скачать» и шагами установки есть в «Настройках», а на главных Яндекса и YouTube она появляется, если расширения нет.

**Chrome, Edge, Яндекс Браузер, Opera:** скачать zip → открыть `chrome://extensions` и включить «Режим разработчика» → перетащить zip на эту страницу. Chrome ставит zip как распакованное расширение, распаковывать не нужно. Запасной путь: распаковать zip и нажать «Загрузить распакованное».

Уже открытые вкладки сайта получают расширение сразу после установки, без перезагрузки: `background.js` подключает `bridge.js` к ним в `onInstalled`.

**Обновление:** поднять `version` в `extension/manifest.json` и выложить сайт. Карточка в «Настройках» сама предложит новую версию: её zip перетаскивается поверх старой. ID расширения закреплён полем `key` в манифесте, поэтому новая версия заменяет старую, а не встаёт рядом. Приватный ключ лежит в `YouCloud-keys/youcloud-extension.pem`: он понадобится только для публикации в Chrome Web Store с тем же ID.

**Firefox:** `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» → скачанный zip. Такое дополнение живёт до перезапуска Firefox. В Firefox расширение пока не проверено.

**Вход в сервисы** делается в «Настройках» и через расширение, токены копировать не нужно:
- **SoundCloud:** войди на soundcloud.com в этом же браузере и нажми «Войти». Расширение возьмёт сессию из cookie `oauth_token`. Без расширения токен можно вставить вручную.
- **YouTube Music:** берёт вход этого браузера на youtube.com. Расширение подписывает запросы сессией (cookie и `SAPISIDHASH`), и cookie не попадают на страницу.
- **Друзья (аккаунт YouCloud):** ник и пароль, тот же аккаунт, что в приложении.
- **Яндекс:** откроется вход Яндекс ID. Расширение поймает токен на странице, куда Яндекс перенаправит после входа, и закроет вкладку. Без Яндекс Плюса треки играют 30 секунд.

Токены хранятся только в localStorage этого браузера.

Расширение работает только на страницах YouCloud (адреса в `content_scripts` манифеста) и ходит только к хостам Яндекса и YouTube из `host_permissions`. Если сайт переедет на другой адрес, его нужно вписать в `matches`.
